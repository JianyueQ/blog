# 前台动态菜单 API 开发文档

**开发日期**: 2026-05-30  
**功能模块**: 前台动态菜单获取接口  
**涉及模块**: mojian-api、blog-web

---

## 一、功能概述

### 1.1 背景说明
前台导航菜单之前采用硬编码方式在 `blog-web/src/layout/Header/index.vue` 中定义，无法动态调整。为了提高菜单管理的灵活性，开发了前台动态菜单获取 API，支持从数据库 `sys_front_menu` 表中读取菜单配置，并支持明暗双图标模式。

### 1.2 功能特性
- ✅ 从数据库动态读取前台导航菜单
- ✅ 支持树形结构（一级菜单 + 子菜单）
- ✅ 支持明暗双图标模式（`icon` 和 `icon_dark` 字段）
- ✅ 支持外链配置（`is_external` 字段）
- ✅ 支持菜单隐藏（`hidden` 字段）
- ✅ 支持菜单状态控制（`status` 字段）
- ✅ 支持自定义排序（`sort` 字段）
- ✅ Redis 缓存加速（Spring Cache）
- ✅ 后台增删改操作自动清除缓存

## 三、后端实现

### 3.1 Controller 层

**文件路径**: `blog/mojian-api/src/main/java/com/mojian/controller/home/FrontMenuController.java`

```java
@RestController
@Tag(name = "门户-前台菜单")
@RequestMapping("/api/frontMenu")
@RequiredArgsConstructor
public class FrontMenuController {

    private final SysFrontMenuService sysFrontMenuService;

    @GetMapping("/navList")
    @SaIgnore
    @Operation(summary = "获取前台导航菜单列表")
    public Result<List<FrontMenuVO>> getNavList() {
        return Result.success(sysFrontMenuService.getNavList());
    }
}
```

**关键点**:
- `@SaIgnore`：无需登录即可访问
- 返回 `FrontMenuVO` 而非实体类，包含明暗双图标字段

### 3.2 Service 层

**文件路径**: `blog/mojian-commom/src/main/java/com/mojian/service/impl/SysFrontMenuServiceImpl.java`

```java
@Override
@Cacheable(cacheNames = Constants.CACHE_FRONT_MENU, key = "'" + Constants.CACHE_FRONT_MENU_NAV + "'")
public List<FrontMenuVO> getNavList() {
    List<SysFrontMenu> menus = list(new LambdaQueryWrapper<SysFrontMenu>()
            .eq(SysFrontMenu::getStatus, 1)  // 只查询启用状态
            .orderByAsc(SysFrontMenu::getSort));  // 按 sort 字段升序
    return buildNavTree(menus);
}

private List<FrontMenuVO> buildNavTree(List<SysFrontMenu> menus) {
    // 转换为 VO
    List<FrontMenuVO> voList = menus.stream().map(m -> {
        FrontMenuVO vo = new FrontMenuVO();
        vo.setId(m.getId());
        vo.setTitle(m.getTitle());
        vo.setPath(m.getPath());
        vo.setIcon(m.getIcon());
        vo.setIconDark(m.getIconDark());  // 暗色图标
        vo.setSort(m.getSort());
        vo.setHidden(m.getHidden());
        vo.setIsExternal(m.getIsExternal());
        vo.setColorClass(m.getColorClass());
        return vo;
    }).collect(Collectors.toList());

    // 构建树形结构
    Map<Integer, List<FrontMenuVO>> childrenMap = voList.stream()
            .filter(vo -> vo.getId() != null)
            .collect(Collectors.groupingBy(vo -> {
                // 找到对应的实体获取 parentId
                SysFrontMenu menu = menus.stream()
                        .filter(m -> m.getId().equals(vo.getId()))
                        .findFirst()
                        .orElse(null);
                return menu != null ? menu.getParentId() : 0;
            }));

    voList.forEach(vo -> vo.setChildren(childrenMap.get(vo.getId())));

    // 只返回顶级菜单（parentId = 0）
    return voList.stream()
            .filter(vo -> {
                SysFrontMenu menu = menus.stream()
                        .filter(m -> m.getId().equals(vo.getId()))
                        .findFirst()
                        .orElse(null);
                return menu != null && menu.getParentId() == 0;
            })
            .collect(Collectors.toList());
}
```

**关键点**:
- `@Cacheable`：使用 Spring Cache + Redis 缓存，键名为 `front_menu::nav_list`
- 只查询 `status = 1` 的启用菜单
- 自动构建父子级树形结构
- 包含 `iconDark` 字段用于暗色模式图标切换

### 3.3 缓存策略

| 操作 | 缓存行为 | 说明 |
|------|----------|------|
| 查询菜单 | 命中缓存 | 优先从 Redis 读取 |
| 新增菜单 | 清除缓存 | `@CacheEvict(allEntries = true)` |
| 修改菜单 | 清除缓存 | `@CacheEvict(allEntries = true)` |
| 删除菜单 | 清除缓存 | `@CacheEvict(allEntries = true)` |

**缓存常量定义**:

#### 4.2.3 新增方法
```javascript
methods: {
  async fetchMenuList() {
    try {
      const res = await getNavListApi()
      if (res.code === 200) {
        // 将后端返回的数据转换为前端需要的格式
        this.menuItems = this.transformMenuData(res.data)
      }
    } catch (error) {
      console.error('获取前台菜单失败', error)
    }
  },
  transformMenuData(data) {
    return data.map(item => {
      const menuItem = {
        name: item.title,
        path: item.isExternal === 1 ? item.path : item.path,
        icon: item.icon,
        iconDark: item.iconDark,
        colorClass: item.colorClass || '',
        external: item.isExternal === 1
      }
      if (item.children && item.children.length > 0) {
        menuItem.children = this.transformMenuData(item.children)
      }
      return menuItem
    })
  },
  // ... 其他方法
}
```

#### 4.2.4 生命周期调用
```javascript

    mutations.forEach((mutation) => {
      if (mutation.attributeName === 'data-theme') {
        this.currentTheme = getThemeMode()
      }
    })
  })
  observer.observe(document.documentElement, { attributes: true })
  
  // ... 其他监听
}
```

#### 4.2.5 明暗图标切换逻辑
```javascript
computed: {
  filteredMenuItems() {
    const isDark = this.currentTheme === 'dark'
    return this.menuItems.map(item => {
      const processItem = (obj) => {
        const processed = { ...obj }
        // 根据主题使用对应的图标字段
        if (isDark && processed.iconDark) {
          processed.icon = processed.iconDark
        } else if (!isDark && processed.icon) {
          processed.icon = processed.icon
        }
        if (obj.children) {
          processed.children = obj.children.map(processItem)
        }
        return processed
      }
      return processItem(item)
    }).map(item => ({
      ...item,
      path: item.children ? item.children[0].path : item.path
    }))
  }
}
```

## 五、数据库结构

### 5.1 表结构

```sql
CREATE TABLE `sys_front_menu` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `parent_id` int(11) NOT NULL DEFAULT 0 COMMENT '父菜单ID，一级菜单为0',
  `title` varchar(50) NOT NULL COMMENT '菜单名称',
  `path` varchar(200) NOT NULL COMMENT '路由路径或外链URL',
  `icon` varchar(100) DEFAULT NULL COMMENT '图标类名（亮色模式）',
  `icon_dark` varchar(100) DEFAULT NULL COMMENT '图标类名（暗色模式）',
  `sort` int(11) NOT NULL DEFAULT 0 COMMENT '显示顺序',
  `hidden` tinyint(4) NOT NULL DEFAULT 0 COMMENT '是否隐藏：0显示 1隐藏',
  `is_external` tinyint(4) NOT NULL DEFAULT 0 COMMENT '是否外链：0否 1是',
  `color_class` varchar(50) DEFAULT NULL COMMENT 'CSS颜色类名',
  `status` tinyint(4) NOT NULL DEFAULT 1 COMMENT '状态：0禁用 1启用',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP,
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='前台菜单表';
```

## 八、注意事项

### 8.1 后端注意事项

1. **缓存一致性**：任何菜单的增删改操作都会自动清除缓存，确保数据一致性
2. **树形结构**：`buildNavTree` 方法会自动构建父子级关系，只需返回顶级菜单
3. **外链处理**：`is_external = 1` 的菜单，前端应使用 `<a>` 标签而非 `<router-link>`
4. **图标字段**：`icon` 和 `icon_dark` 可以为空，前端应做空值判断

### 8.2 前端注意事项

1. **数据格式转换**：后端返回的字段名与前端使用的不完全一致，需要转换
   - `title` → `name`
   - `isExternal` → `external`
2. **图标切换逻辑**：`filteredMenuItems` 计算属性会自动根据主题选择对应图标
3. **错误处理**：API 调用失败时，`menuItems` 保持为空数组，不会导致页面崩溃
4. **性能优化**：菜单数据只在 `mounted` 时加载一次，后续使用缓存
